# PayFlow — Design Guidelines

## 1. Aesthetic Principles
- **Theme:** Modern, sleek, professional fintech aesthetic.
- **Palette:** 
  - Primary Slate/Indigo: Deep midnight navy `#0B0F19`, Slate `#1E293B`, Cool Gray `#64748B`, Crisp White `#FFFFFF`
  - Accents: Emerald `#10B981` (Success), Amber `#F59E0B` (Pending/Warning), Rose `#EF4444` (Failed/Error), Indigo `#6366F1` (Action/Brand)
- **Typography:** Modern sans-serif (Inter / system fonts), distinct font weights (500/600 for headings, 400 for body).
- **Component Style:** Crisp thin borders (`border-slate-200` / `dark:border-slate-800`), subtle shadows, rounded corners (`rounded-xl`), readable data tables with alternating hover states.
- **Visuals:** Lucide icons for semantic iconography, Recharts for dynamic visual metrics.
